# 🛠️ rumi-agent-builder - Build smart AI agents with ease

[![](https://img.shields.io/badge/Download-Rumi_Agent_Builder-blue.svg)](https://github.com/bettyelyrical824/rumi-agent-builder)

Rumi Agent Builder gives you a visual space to create custom AI agents. You connect blocks on a canvas to design how your agent thinks, speaks, and acts. You do not need to write code to build complex AI workflows. The tool offers thirteen unique block types to handle data, logic, and conversation. Your team can work on the same project at the same time to speed up development.

## 📦 System Requirements

Your computer must meet these basic needs to run the software.

*   **Operating System:** Windows 10 or Windows 11.
*   **Memory:** At least 8 gigabytes of RAM.
*   **Storage:** 500 megabytes of free space on your hard drive.
*   **Internet:** A stable connection to download updates and sync projects.

## 📥 Getting Started

Follow these steps to set up the software on your Windows machine.

1.  Visit the [official download page](https://github.com/bettyelyrical824/rumi-agent-builder). 
2.  Look for the latest version under the Releases section.
3.  Download the file that ends in .exe.
4.  Double-click the file to start the installation.
5.  Follow the prompts on your screen to complete the process.
6.  Open the Rumi Agent Builder icon from your desktop or start menu.

## 🧱 Understanding the Canvas

The canvas is the main work area. You pull blocks from the menu on the left and drop them onto the screen. Each block represents a specific task for your AI agent. You link blocks with lines to show the order of operations.

### Block Types
*   **Input Blocks:** Collect information from the user or external files.
*   **Logic Blocks:** Make decisions based on set rules.
*   **Action Blocks:** Trigger the AI to perform a specific task.
*   **Storage Blocks:** Save information to your local database.

The tool uses SQLite to keep your data organized and secure on your own machine. You remain in control of all information your agents process.

## 🤝 Collaborative Features

Rumi Agent Builder supports real-time teamwork. Multiple people can view and edit the same canvas at once. You see changes as they happen. This helps teams build complicated agents faster. You can share your design files with colleagues by sending the project file directly or by uploading it to a shared workspace.

## 🤖 AI-Assisted Authoring

Building an agent involves many steps. The built-in assistant helps you write prompts and logic rules. You describe what you want the agent to do in plain English. The software suggests the correct blocks and settings to make that happen. This feature removes the trial and error often found in automation tools.

## 🔧 Managing Your Workspace

Your workspace holds all your active projects. You can create folders to group agents by type or purpose. The settings menu allows you to change the appearance of the canvas or configure your preferences. 

If you encounter issues, look for the log file in the settings tab. This file keeps a record of actions the software takes. You can send this file to support if you need help fixing a problem.

## 🛡️ Privacy and Security

Your work stays on your computer. You choose when to sync your projects or share them with others. No outside party has access to your agents unless you explicitly provide that access. All your data remains in your local folders.

## ❓ Troubleshooting

Sometimes software faces issues during setup or use. These tips help you resolve common problems.

*   **Software fails to launch:** Ensure your firewall allows Rumi Agent Builder to access the local network. 
*   **Canvas feels slow:** Close other programs that use lots of memory, such as web browsers with many tabs.
*   **Unable to save files:** Check that you have enough disk space on your local computer.
*   **Collaboration does not work:** Make sure everyone on your team has the same version of the software.
